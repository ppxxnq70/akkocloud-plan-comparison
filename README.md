## 三个机房怎么选：延迟、线路、原生 IP

网络正常的情况下，三个机房的国内延迟大致是圣何塞 168ms、法兰克福 180ms、伦敦 200ms 出头。差距在几十毫秒的量级，对建站和日常代理的体感影响有限，真正决定选哪个的是目标用户在哪个区域，以及要不要原生 IP。

圣何塞国内访问最成熟。三网回程走 CN2 GIA，电信去程也是 CN2 GIA，晚高峰不容易出现普通 163 线路那种丢包爬升。第三方测评给出的延迟约 168ms，非高峰期下载速度 6MB/s 左右。IP 分两个网段：38 段是原生 IP，可以直接解锁 Netflix、Disney+；185 段不保证原生。

法兰克福的延迟约 180ms，一般欧洲 VPS 在 230ms 以上。电信和联通去程走 GIA，移动去程直连，三网回程 CN2 GIA，丢包率低，晚高峰表现稳定。给的是德国原生 IP，可解锁德国区流媒体。

伦敦延迟 200ms 出头，线路在 CN2 GIA 之外还叠了 CMI、CMIN2 优化，移动线路后来升级到 CMIN2，电信联通去程也走 GIA。I/O 表现不错，适合既要欧洲落地又不想延迟太高的场景。

原生 IP 这条要单独讲。官方 ToS 写明 Looking Glass 的测试 IP 不代表你实际拿到的网段，货池里 38 段和 185 段混着分配，下单时没法指定。所以“这台机器能不能解锁 Netflix”在付款那一刻没有确定答案，官方也明确谢绝以“不是原生 IP”为由申请退款。需要稳定解锁特定区内容的，把这条当成硬约束来看，别赌。
